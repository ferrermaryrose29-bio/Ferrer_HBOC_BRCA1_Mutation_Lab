## Overview

This repository documents a molecular biology laboratory tracing a BRCA1 mutation from DNA sequence change to predicted protein consequence and disease mechanism. Two frameshift deletions were analyzed: the documented pathogenic variant c.68_69delAG, and a self-designed artificial variant, c.500delC. Both disrupt the BRCA1 reading frame and produce severely truncated, predicted non-functional proteins (38 aa and 232 aa respectively, versus 1,863 aa wild-type), supporting the mechanism by which loss-of-function BRCA1 mutations impair DNA repair and contribute to hereditary breast/ovarian cancer.
